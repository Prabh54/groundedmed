3 · Not enough evidence

When the abstracts found aren't close enough, the server skips writing and checking. The slim row shows those two steps as a grey dash ("skipped"), above today's "Not enough evidence" card with Becky's apologetic shrug.

  1. ✓Planning
  2. ✓Retrieving · nothing close enough
  3. –Synthesizing · skipped
  4. –Checking claims · skipped

4 · Something went wrong

If a step fails (for example the AI service is down), that step gets a red ✕ and "didn't finish"; later steps stay empty. Becky stops reading and shrugs. The red box is the same plain error message as today.
